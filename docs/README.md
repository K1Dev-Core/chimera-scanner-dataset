# Docs

โฟลเดอร์นี้รวมเอกสารอธิบาย project แยกตามหน้าที่ เพื่อไม่ให้ไฟล์ markdown กองอยู่หน้า repo

## ควรอ่านก่อน

1. `overview/DEC-DATASET-GUIDE-TH.md` ภาพรวม dataset, records, raw-curated, Hex import และ feature ที่ควรใช้
2. `status/DEC-CURRENT-STATUS.md` สถานะล่าสุดของงาน Dec
3. `status/HEX-BRANCH-PROGRESS-2026-08-05.md` สรุปของที่นำเข้าจาก branch Hex

## หมวดเอกสาร

| path | ใช้ทำอะไร |
| --- | --- |
| `overview/` | ภาพรวม project และคู่มือเริ่มต้น |
| `guides/` | บทความ/cheatsheet/feature recommendation |
| `kali/` | คู่มือ tool stack และ script install ฝั่ง Kali |
| `prompts/` | prompt สำหรับ agent/subagent |
| `runs/` | บันทึกการรัน scan/normalize |
| `status/` | checklist, progress, current status |
