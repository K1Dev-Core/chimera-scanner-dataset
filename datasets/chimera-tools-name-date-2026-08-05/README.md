# Chimera Scanner Dataset (2026-08-05)

This package contains raw scanner reports and normalized JSON/JSONL records generated by Chimera.

## Layout

- `datasets/tools-name-date/<tool>-<date>/<run-id>/normalized/` normalized records per scanner.
- `datasets/tools-name-date/<tool>-<date>/<run-id>/raw/` original scanner outputs.
- `records/all-findings.jsonl` cross-tool finding rows for quick dataset loading.
- `manifests/index.json` package index and provenance.
- `manifests/checksums.sha256` integrity hashes.
