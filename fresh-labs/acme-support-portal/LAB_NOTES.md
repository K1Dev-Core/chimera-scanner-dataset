# Acme Support Portal

Fresh unseen lab สำหรับทดสอบ Chimera / Exploit-DL

เว็บนี้ทำให้ดูเหมือน internal support/helpdesk portal ที่ใช้งานจริง มีหน้า dashboard, tickets, assets, comments, diagnostics และ reports

## Intended vulnerability families

- SQL injection
- Stored XSS
- IDOR / broken access control
- Path traversal
- Command injection
- Sensitive data exposure

## Safety

Lab นี้ตั้งใจให้รันบน localhost เท่านั้น

อย่า deploy ขึ้น public internet
